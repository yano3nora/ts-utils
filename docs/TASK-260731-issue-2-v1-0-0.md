## notes

skip 判断 (2026-07-31 人間確認済み):

- **crypto (gist 422183f)**: Node の `crypto` 依存で runtime
  非依存原則に反するうえ、固定 IV 再利用というセキュリティ的に悪い実装。
  取り込むなら要再設計で別タスク規模のため skip
- **filterTruthy (gist 24a54d8)**: es-toolkit の `compact` と丸かぶり (falsy
  除去 + 型 narrow)。ADR-0001 の es-toolkit ゲートにより追加しない
- **objects2object 型修正**: ADR-0001 で `@deprecated` (es-toolkit の `keyBy`
  へ移行) にしたため型改修は行わない。型付きの代替は既存の `recordBy` にもある

その他:

- 既存関数との重複チェック済み: `charCount` は書記素数カウント、`objectIncludes`
  は値検索なので今回の取り込みと競合しない
- issue の operation (npm publish 2FA) と utils/formatter のチェック済み項目は
  対応済みだった
- issue のチェックボックス更新・クローズは人間が行う

codex exec レビュー結果 (2026-07-31 反映済み):

- `objectHas` の false 側は unsound (未設定 optional property / prototype 由来
  property は hasOwn が false になるが keyof T ではある) → JSDoc へ NOTE 追記 +
  optional property のテスト追加
- `intlDateFormat` の locale 文字列直接加工 (replace/split) は ICU 実装差に弱い
  → `formatToParts` で組み立てる実装へ変更、4 桁未満の年は padStart で揃え、
  local timezone 依存を JSDoc に明記
- `substrCount` / `main.ts` export 順 / 命名・フォーマットは指摘なし
